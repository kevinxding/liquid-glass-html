# Liquid Glass

Browser study of [luciascarlet/gpui-glass-demo](https://github.com/luciascarlet/gpui-glass-demo).

Open [index.html](./index.html) in a WebGL2 browser (Chrome, Edge, Safari). Drag the glass, scroll the tiles, and switch 玻璃 / 清透 / 磨砂 / 棱镜.

The upstream project is a macOS GPUI + Metal experiment. This file is an original WebGL approximation of its public material parameters (edge refraction, dispersion, frost, fog, rim light). It does not include or copy their WGSL shaders.

The native repository fork was requested as well; if GitHub is still finishing that fork it will show up separately under this account.
